L.D.PORTO VIDEO ANALYZER - pacote para ChatGPT Work

Raiz original:
/mnt/data/ldporto_work

Este pacote foi criado para conter somente codigo-fonte, configs, testes,
documentacao, scripts de instalacao/diagnostico e metadados pequenos.

Excluidos de proposito:
- .venv / venv
- videos e audios
- modelos binarios
- DLLs / wheels / executaveis
- caches
- downloads/input
- imagens/thumbnails
- ZIPs anteriores
- arquivos com nomes que sugerem tokens/cookies/credentials

Amostra da analise mais recente incluida: False
Fonte da amostra: nenhuma

Antes de alterar o codigo, o Work deve ler:
1. WORK_PACKAGE_MANIFEST.json
2. WORK_PACKAGE_PROJECT_TREE.txt
3. README/LEIA_PRIMEIRO/docs
4. src/ldporto inteiro
5. tests inteiro
6. configs/requirements/BATs
7. sample analysis, se presente

Nao recriar o projeto do zero.

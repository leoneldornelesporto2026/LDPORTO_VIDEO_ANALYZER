# Exemplos

mapping_example.json demonstra o formato de associação manual.
Não aponta participantes reais nem deve ser usado antes de conferir seus IDs.

sintética. A fala foi fornecida por anotação controlada; não é transcrição de
uma entrevista ou resultado acústico validado.
